Chapter 1 · Autoregression

One word at a time.

Every model here plays the same game: given what has been written so far, guess the next word. Then do it again. That loop is what “autoregressive” means — and it is the same idea behind today's largest language models.

  1. 01

    Read

    Words become numbers. The model looks only at the last 24 — its context window.

  2. 02

    Predict

    It scores all 8,000 words in its vocabulary. Most get almost nothing; a few light up.

  3. 03

    Pick & repeat

    One word is chosen, appended, the window slides forward — and the loop runs again.

Chapter 3 · The contenders

Four minds, one rulebook.

Same vocabulary, same 24-word window, same embedding and hidden sizes, same optimiser, same training budget, three random seeds each. The only thing that changes is how each network remembers.
